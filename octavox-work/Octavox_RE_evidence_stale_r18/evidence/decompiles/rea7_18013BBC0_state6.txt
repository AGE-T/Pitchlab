Interpretation (OBS): [T+0x5FD0] is the gatelevel, [T+0x5FC8] points to a two-float
record (magnitude, level). A new magnitude is accepted only while
gatelevel - level < FLT_EPSILON, i.e. level > gatelevel. With a dB value this is an
adaptive gate that freezes the magnitude below threshold. With the power ratio
10^(g/10) the subtraction is between incommensurable quantities
(3.16e-6 - (-20) > eps), so the update would never happen - see the CONFLICT in
section 10.2. The state machine then advances to state 7 (0x18013D117).
