OCTAVOX 16.0.0 -- DEFAULT-CONFIG NEUTRALITY REFERENCE HASHES (R19)
=======================================================================
Recorded 2026-10-31 (round 19). These four FNV-1a-64 hashes are the
16.0.0-DEFAULT reference record (the decimated control-rate detector +
click-free spacing commits + crossfaded base-delay changes + voice
activation ramps; see dsp.hpp's ROUND-19 CONTRACT). The 15.0.0 record
(r15_reference_hashes.txt) STILL REPRODUCES BIT-EXACTLY under the legacy
configuration pins {detector_mode = FullRate, commit_crossfade_seconds = 0,
delay_crossfade_seconds = 0, voice_fade_seconds = 0} -- gated by the
default_neutrality case (legacy-pinned; gate values unchanged) and the
octavox_r15refcap --legacy run below.

PROTOCOL
--------
Tool:  native/cli/r15ref_capture.cpp (CMake target octavox_r15refcap).
       ./build/octavox_r15refcap             -> the four 16.0.0 hashes below
       ./build/octavox_r15refcap --legacy    -> the four 15.0.0 hashes
       ./build/octavox_r15refcap --probe96   -> detector probe, BOTH modes
Hash:  FNV-1a 64 over the raw output float bits (little-endian bytes), the
       same law as the acceptance suite's default_neutrality cases.
Input: pure-formula generators (shared 64-bit LCG spec / sine / chirp),
       N = 2^18 = 262144 samples per config at 48 kHz, fixed cycling block
       patterns -- fully deterministic.

THE FOUR CONFIGURATIONS (all 16.0.0 defaults unless stated)
------------------------------------------------------------
cfg1  default unity + deterministic LCG noise (seed 987654321, amp 0.5);
      blocks 64/150/512 mixed.
cfg2  ratio 2^(700/1200), 8 voices, spread on, feedback 0.25, 220 Hz sine
      (amp 0.5); blocks 150/512/64.
cfg3  ratio 2^(-400/1200), 4 voices, spread off, chirp 200->800 Hz
      (amp 0.5); blocks 64/512/150.
cfg4  MultichannelShifter stereo 2ch, different per-channel inputs (LCG
      seeds 1111111111 / 2222222222, amp 0.4), 4 voices, unity ->
      2^(400/1200) mid-stream (setRatio at the first block boundary at/after
      N/2); blocks 1024/64/512. Hash = L bits then R bits in ONE FNV stream.

cfg1 is IDENTICAL to the 15.0.0 record (0x74318b06c182aacb): a unity voice
parks, never wraps, and its parked integer read is detector- and
commit-independent -- the bit-exact neutrality of the unity path carries
through the whole 16.0.0 refactor. cfg2/3/4 legitimately change (the
decimated detector produces different estimates and the spacing commits now
crossfade instead of stepping -- the measured click fix).
